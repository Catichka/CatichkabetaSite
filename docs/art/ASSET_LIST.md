# Art on the site, and what's still wanted

## How to hand art to Claude
1. Put each batch in its own folder, `docs/art/<name>-v01/`, with a short `CLAUDE_HANDOFF.md` saying what each file is and where it goes.
2. Commit on a branch and open a pull request, or give the files to Cat to upload in the Claude thread.
